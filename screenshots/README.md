# Screenshots

Add only reviewed, non-sensitive screenshots here.

Recommended safe screenshots:

- Public homepage
- Public market page
- Public blog page
- A demo-only skill detail page
- A demo-only chat response with fake or public test data

Do not add screenshots containing:

- admin pages
- private wallet balances
- seed phrases or keys
- API keys
- production database records
- private prompts
- private skill workflows
- deployment terminals
- server IP addresses
